## Cohérence inter-parties

- Problème / personas : le DAF lit les résultats économiques et le directeur des opérations examine les volumes/vacations.
- Solution / valeur / MVP : **consolidation, réalisé/budget, benchmark contextualisé, alertes et transparence**.
- Assistant IA conversationnel : **idée citée et conservée**, **V3** dans le cadrage, non opérationnel dans le MVP.
- Données : **exemples synthétiques uniquement** dans le dépôt ; sources réelles citées comme candidates non vérifiées.
- H1 / SMART / CRISP-DM / MVP / deck : **trois écarts**, **cible de réduction de temps ≥ 30 %**, **exactitude non dégradée**, **six semaines proposées**.
- Seuil de démonstration alertes **−10 %** distinct du seuil de succès métier **30 %**.
- Aucune simulation ne se substitue à un entretien, un vote ou un résultat utilisateur.

## Risques résiduels bloquants

1. Preuves authentiques de divergence/convergence : Crazy 8, vote et matrice.
2. Modèle VPC des annexes du cours.
3. Membres du groupe et commits personnels.
4. Exécution éventuelle du protocole : ne pas prétendre avoir testé sans mesures.
5. Prompts initiaux à récupérer si disponibles.
6. Vérification accès enseignante et dépôt final.

**Conclusion :** documentation techniquement et méthodologiquement cohérente, mais **conformité à 100 % non certifiée** tant que les preuves ci-dessus manquent.
