# RADIOPILOT
Ce projet vise à exploiter les données d’activité des centres d’imagerie médicale pour suivre les indicateurs de performance, détecter rapidement les écarts, identifier leurs causes et faciliter la prise de décision. L’objectif est d’optimiser les ressources, d’améliorer l’efficacité opérationnelle et de renforcer le pilotage des activités.
